# Tienda Online
**Autor:** Gabriel Gascón

Aplicación en Python que modela una tienda online con productos, usuarios y pedidos. En las siguientes prácticas evolucionará a una API REST con FastAPI.

## Estructura
- `models/` → clases del dominio (Producto, Usuario, Pedido...)
- `Services/` → lógica de la tienda (TiendaService)
- `main.py` → programa principal

## Cómo ejecutarlo
python main.py
